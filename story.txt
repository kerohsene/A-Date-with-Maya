# COMMANDS
#   maya: text           Maya speaks          mc: text     the player speaks
#   "text"               narration / the MC's thoughts (no name tab)
#   scene name           switch background (clears sprites)
#   show maya center happy      show / change a sprite (left, center, right)
#   hide maya            remove a sprite
#   wait 1.5             hide the text box and pause 1.5 seconds (plain "wait" = 1)
#   cg name / cg off     show / leave full-screen event art (unlocks in the Gallery)
#   menumusic name       the song for the title screen (defined with "track")
#   music name           play a song defined with "track" (or the built-in pads: calm, tense; "music off" stops)
#   credits ... end credits   a timed credits roll, one line at a time (see the bottom of this file)
#   paper ... end paper       a sheet of paper shown full screen; click to turn to the next one
#   end                  finish the story
#   {player}             the name typed on New Game
#
# Lines starting with # are comments and are ignored.
